# Date Duel — игра для двоих в браузере

Оригинальная браузерная игра для пары, вдохновлённая общими механиками story-driven board games: два игрока, общая доска, код комнаты, бросок кубика, покупка мест, уровни заданий и две категории победы.

## Быстрый запуск на двух компьютерах в одной Wi‑Fi сети

1. Установите Node.js 20+ на компьютере-хосте.
2. Распакуйте проект и в папке выполните:
   ```bash
   npm install
   npm start
   ```
3. На компьютере-хосте откройте `http://localhost:3000`.
4. Узнайте локальный IP хоста:
   - Windows: `ipconfig` → IPv4 Address
   - macOS: System Settings → Network → Wi‑Fi → Details → TCP/IP
5. На втором компьютере в той же сети откройте `http://IP_ХОСТА:3000`, например `http://192.168.1.25:3000`.
6. Первый игрок создаёт комнату и сообщает 5-символьный код второму.

Если Windows спросит доступ для Node.js через Firewall — разрешите для Private networks.

## Игра через интернет из разных сетей

Разверните этот проект на любом Node.js-хостинге с WebSocket/Socket.IO (Render, Railway, Fly.io и т.п.). Команда запуска: `npm start`. После деплоя оба игрока открывают один публичный URL.

## Что уже работает

- Комнаты по коду
- Синхронизация двух браузеров через Socket.IO
- 3 режима: Романтика, Флирт, После полуночи
- Кубик и движение по общей доске
- Покупка клеток
- Free Pass и Wildcards
- Уровни Нежно / Флирт / Смело
- Деньги + «искры»
- 16 сюжетных глав/заданий
- Финал с двумя победителями/коронами
